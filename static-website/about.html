The Stack

How this site gets from code to cloud.

01

Jenkins

Orchestrates the entire CI/CD pipeline. Triggered on every push to the main branch. Runs SonarQube analysis, evaluates the Quality Gate, and executes the S3 deployment.

02

SonarQube

Performs deep static code analysis. Checks for HTML/JS/CSS issues, security vulnerabilities, duplications, and code smells. If the Quality Gate fails, the pipeline aborts — nothing broken ships.

03

AWS S3

Hosts all static files with native static website hosting enabled. Files are synced using aws s3 sync — only changed files are uploaded, keeping deployments fast.

04

IAM + Credentials

A dedicated IAM user with scoped S3 permissions is used. Credentials are stored securely in Jenkins as Secret Text — never hard-coded in the pipeline.
